I led a lunch-n-learn session detailing mainframe emulation on a Raspberry Pi Zero. Topics covered:

* What is a mainframe?
* History of the mainframe
* Mainframes today
* Misconceptions
* Requirements
* Host Setup and Installation
* Host Startup
* Client Setup
* Operations:
  * Logon
  * JCL and Programming; COBOL, FORTRAN, PL/1, and C
  * Logoff and Shutdown
